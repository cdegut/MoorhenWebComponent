Moorhen as a Web Component

A plain TypeScript page that embeds <moorhen-web-component>, drives it from ordinary DOM code, and listens to what it reports back. No framework involved.

Register the element, then wait for it

import { registerMoorhenWebComponent } from "moorhen/web-component";

registerMoorhenWebComponent();

Then use the tag in your markup. It needs an id, and it takes its size from the box you put it in: 

<div class="viewer">
    <moorhen-web-component id="moorhen-1"></moorhen-web-component>
</div>
.viewer {
    display: flex;
    height: 70vh;   /* the container needs a definite height */
}

The element below is sized that way. It follows its container, so it grows and shrinks with the window. Setting width and height attributes instead gives it a fixed size.

Those four lines are live. The demo subscribes to the molecule list, to atom-hover events, to file loading and to molecule changes, and writes whatever it receives into them.

Loading a file updates the first and third lines: the count comes from the store, and the files-loaded callback reports the file names together with the optional origin label you pass to loadFiles(). The last line comes from the molecule-change callback, which also fires for edits you make in the viewer (mutate, refine, delete, and so on) and sometimes during loading, without an action and before the molecule is listed.

The menu bar is extended in two ways. An Extra Menu entry gets its own submenu, and a Page controls entry whose only item is an HTML slot: the slot is filled by markup placed inside the <moorhen-web-component> element, so those buttons are ordinary page DOM, styled by this page’s CSS. 

<moorhen-web-component id="moorhen-1">
    <div slot="page-controls" class="slot-controls">
        <button id="slot-load-1bxn">Load 1BXN</button>
        <button id="slot-toggle-theme">Toggle theme</button>
    </div>
</moorhen-web-component>

Serving the page: Moorhen needs a cross-origin isolated page, and vite.config.ts already sets the two required headers for the dev server. Check window.crossOriginIsolated in the console: it must be true.

A plugin: a modal of your own, with Moorhen’s controls

The Plugin menu entry opens a modal whose content is markup of this page, given to Moorhen through a slot. The controls in it are Moorhen’s own, as custom elements defined by registerMoorhenWebComponent(): they look like the rest of Moorhen, follow its theme, and the molecule and chain lists show what is loaded in it. 

<moorhen-web-component id="moorhen-1">
    <div slot="example-plugin">
        <moorhen-toggle id="plugin-axes">Draw axes</moorhen-toggle>
        <moorhen-slider id="plugin-zoom" label="Zoom" min="0.05" max="5" scale="log"></moorhen-slider>
        <moorhen-molecule-select id="plugin-molecule" label="Molecule"></moorhen-molecule-select>
        <moorhen-chain-select for="plugin-molecule" multiple label="Chains"></moorhen-chain-select>
    </div>
</moorhen-web-component>
moorhenInstance.uiExtensions.addModal({ id: "example-plugin", title: "Example plugin", slotName: "example-plugin" });
moorhenInstance.menuSystem?.addMainMenu({ type: "modal", label: "Plugin", icon: "MatSymAdd", modal: "example-plugin" });

// The controls work like <input>: properties for the value, `change` and `input` events
const axes = document.getElementById("plugin-axes") as MoorhenToggleElement;
axes.addEventListener("change", () => moorhenInstance.sceneSettings.setDrawAxes(axes.checked));
// …and follow Moorhen, whatever changes the setting
moorhenInstance.subscribeToStore(s => s.sceneSettings.drawAxes, drawAxes => (axes.checked = drawAxes));

The chain list follows the molecule select through its for attribute, with no code. See src/plugin.ts for the whole plugin.

The elements also work outside Moorhen: the Spin switch and the Centre on molecule list next to the buttons above are a <moorhen-toggle> and a <moorhen-molecule-select> in the page: the list shows the molecules loaded in Moorhen, and picking one centres the view on it. With a single Moorhen in the page it finds it by itself; with several, give the id of one in a moorhen attribute: <moorhen-toggle moorhen="moorhen-1">.

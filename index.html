Moorhen as a Web Component

This demo shows two ways to use Moorhen: directly with <moorhen-web-component/>, and by extending MoorhenWebComponent to add custom actions.

1) Default Component

Use Moorhen directly in HTML without extra app code.

import { MoorhenWebComponent } from "moorhen"

2) Custom Extended Component

Extend the class to inject extra menu entries and expose custom controls.

class MyMoorhen extends MoorhenWebComponent { ... }
